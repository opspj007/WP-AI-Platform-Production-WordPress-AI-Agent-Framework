# WP AI Platform — Production WordPress AI Agent Framework

**WP AI Platform** is a production-oriented WordPress plugin framework for building **AI-powered websites, customer support agents, knowledge systems, and automation workflows**.

## 🚀 Features

- 🤖 Gemini & OpenAI integration
- 💬 AI customer-support chatbot
- 🧠 AI Agent architecture
- 📚 Knowledge Base & RAG foundation
- 🔌 Extensible tool calling
- 🔗 WordPress REST API
- 👥 Lead collection & management
- 🛒 WooCommerce integration
- 📊 AI usage & audit logging
- 🔐 Rate limiting & security controls
- ⚡ Custom database architecture
- 🧩 Extensible AI provider architecture

## 🏗️ Architecture

```text
WordPress
│
├── AI Chat

├── Tool Registry
├── Lead Management

        ▼
```

## 🛠️ Tech Stack

**PHP • WordPress • MySQL • REST API • JavaScript • Gemini • OpenAI • WooCommerce**

## 📦 Installation

Clone or download the repository and place the plugin in:

```text
wp-content/plugins/wp-ai-platform/
```

Activate it from **WordPress → Plugins**, then configure the AI provider from **WP AI Platform** in the WordPress admin dashboard.
